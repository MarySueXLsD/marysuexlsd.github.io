MaryS Game Engine

MaryS Game Engine is a modular 2D turn-based game engine on C# and MonoGame, with a drag-and-drop editor and an AI assistant, by Loosy Tale Studio.

View on GitHub ↗

About MaryS Game Engine

MaryS Game Engine is a user-friendly 2D game engine focused on turn-based games, built in C# on MonoGame. It is meant to let developers, including people who don’t code, make turn-based games with minimal coding.

The editor works like a small desktop: a Desktop folder holds the start screen, a Modules folder holds the editor tools, and a Games folder holds each game project. Every tool, from the scene editor to the asset browser, is a module the engine discovers and loads at runtime, and removing a module disables its features.

Whatever a module makes stays in the game’s own folder, so a game keeps working even if the tool that built it is removed. Game projects can be run inside the engine for testing and exported as standalone MonoGame projects.
