Tools

Engines, mods, bots and music tools we built along the way, all open source on GitHub.

Game engine · C#

MaryS Game Engine

MaryS Game Engine is a modular 2D turn-based game engine on C# and MonoGame, with a drag-and-drop editor and an AI assistant, by Loosy Tale Studio.

 Music tool · Rust

SensePad

SensePad turns a PlayStation DualSense controller into a drum machine for Windows, with pads, a looper and DJ effects. Written in Rust by Loosy Tale Studio.

 Game mod · Lua

Silent Hill 2 Co-op Mod

An experimental two-player co-op mod and launcher for Silent Hill 2 (2024), written in Lua. An unofficial fan project by Loosy Tale Studio.

 AI assistant · TypeScript

Maris Local AI

Maris Local AI is a private AI assistant that runs entirely on your PC: chat, a coding agent, memory, web browsing, and local image and video generation.

 VS Code extension · JavaScript

Travelling Kingdom

Travelling Kingdom is a sidebar travel companion for VS Code and Cursor: walk the road, visit destinations and recruit companions while you code.

 Twitch bot · TypeScript

Brackets

Brackets is a Twitch chat bot that answers your viewers in your own manner while you play, with a launcher that shows every reply and why.
