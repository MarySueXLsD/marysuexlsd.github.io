Інструменти

Рушії, моди, боти й музичні інструменти, які ми зробили по дорозі. Увесь код відкритий на GitHub.

Ігровий рушій · C#

MaryS Game Engine

MaryS Game Engine це модульний 2D-рушій для покрокових ігор на C# і MonoGame від Loosy Tale Studio, з редактором, де все перетягується мишею, і ШІ-помічником.

 Музичний інструмент · Rust

SensePad

SensePad перетворює контролер PlayStation DualSense на драм-машину для Windows із падами, лупером і DJ-ефектами. Loosy Tale Studio написала його на Rust.

 Мод для гри · Lua

Silent Hill 2 Co-op Mod

Експериментальний кооперативний мод на двох гравців і лаунчер для Silent Hill 2 (2024), написаний на Lua. Неофіційний фанатський проєкт Loosy Tale Studio.

 ШІ-помічник · TypeScript

Maris Local AI

Maris Local AI це приватний ШІ-помічник, який повністю працює на вашому ПК: чат, агент для програмування, пам’ять, перегляд вебсторінок і локальна генерація зображень і відео.

 Розширення для VS Code · JavaScript

Travelling Kingdom

Travelling Kingdom це маленька подорож у бічній панелі VS Code і Cursor: ідіть дорогою, відвідуйте місця й збирайте супутників, поки пишете код.

 Бот для Twitch · TypeScript

Brackets

Brackets це бот для чату Twitch, який відповідає вашим глядачам у вашій манері, поки ви граєте, а його лаунчер показує кожну відповідь і її причину.
