MaryS Game Engine

MaryS Game Engine це модульний 2D-рушій для покрокових ігор на C# і MonoGame від Loosy Tale Studio, з редактором, де все перетягується мишею, і ШІ-помічником.

Про MaryS Game Engine

MaryS Game Engine це зручний 2D-рушій для покрокових ігор, написаний на C# на базі MonoGame. Його задумано так, щоб розробники, зокрема ті, хто не програмує, могли робити покрокові ігри з мінімумом коду.

Редактор влаштований як маленький робочий стіл: у теці Desktop лежить стартовий екран, у теці Modules інструменти редактора, а в теці Games усі ігрові проєкти. Кожен інструмент, від редактора сцен до браузера ресурсів, це модуль, який рушій сам знаходить і завантажує під час роботи, а якщо модуль прибрати, його функції зникають.

Усе, що створює модуль, лишається в теці самої гри, тож гра працює далі, навіть якщо інструмент, яким її зробили, видалити. Ігрові проєкти можна запускати всередині рушія для тестування й експортувати як окремі проєкти MonoGame.
