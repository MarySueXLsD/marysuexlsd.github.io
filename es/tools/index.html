Herramientas

Motores, mods, bots y herramientas musicales que hemos ido creando por el camino, todo de código abierto en GitHub.

Motor de juegos · C#

MaryS Game Engine

MaryS Game Engine es un motor modular de juegos 2D por turnos en C# y MonoGame, con editor de arrastrar y soltar y un asistente de IA, de Loosy Tale Studio.

 Herramienta musical · Rust

SensePad

SensePad convierte un mando DualSense de PlayStation en una caja de ritmos para Windows, con pads, un looper y efectos de DJ. Escrito en Rust por Loosy Tale Studio.

 Mod de juego · Lua

Silent Hill 2 Co-op Mod

Un mod experimental de cooperativo para dos jugadores y un lanzador para Silent Hill 2 (2024), escrito en Lua. Un proyecto fan no oficial de Loosy Tale Studio.

 Asistente de IA · TypeScript

Maris Local AI

Maris Local AI es un asistente de IA privado que funciona íntegramente en tu PC: chat, un agente de programación, memoria, navegación web y generación local de imágenes y vídeo.

 Extensión de VS Code · JavaScript

Travelling Kingdom

Travelling Kingdom es un compañero de viaje en la barra lateral de VS Code y Cursor: recorre el camino, visita destinos y recluta compañeros mientras programas.

 Bot de Twitch · TypeScript

Brackets

Brackets es un bot para el chat de Twitch que responde a tus espectadores a tu manera mientras juegas, con un lanzador que muestra cada respuesta y su motivo.
