MaryS Game Engine

MaryS Game Engine es un motor modular de juegos 2D por turnos en C# y MonoGame, con editor de arrastrar y soltar y un asistente de IA, de Loosy Tale Studio.

Ver en GitHub ↗

Sobre MaryS Game Engine

MaryS Game Engine es un motor de juegos 2D fácil de usar, centrado en juegos por turnos y creado en C# sobre MonoGame. Su objetivo es que los desarrolladores, incluidas las personas que no programan, puedan hacer juegos por turnos con un mínimo de código.

El editor funciona como un pequeño escritorio: una carpeta Desktop contiene la pantalla de inicio, una carpeta Modules contiene las herramientas del editor y una carpeta Games contiene cada proyecto de juego. Cada herramienta, del editor de escenas al explorador de recursos, es un módulo que el motor descubre y carga en tiempo de ejecución, y quitar un módulo desactiva sus funciones.

Todo lo que crea un módulo se queda en la carpeta del propio juego, así que un juego sigue funcionando aunque se elimine la herramienta con la que se hizo. Los proyectos se pueden ejecutar dentro del motor para probarlos y exportar como proyectos independientes de MonoGame.
