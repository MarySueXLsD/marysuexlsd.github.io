Tools

Engines, Mods, Bots und Musik-Tools, die wir unterwegs gebaut haben, alle Open Source auf GitHub.

Game-Engine · C#

MaryS Game Engine

MaryS Game Engine ist eine modulare 2D-Engine für rundenbasierte Spiele auf C# und MonoGame, mit Drag-and-drop-Editor und KI-Assistent, von Loosy Tale Studio.

 Musik-Tool · Rust

SensePad

SensePad verwandelt einen PlayStation-DualSense-Controller in einen Drumcomputer für Windows, mit Pads, Looper und DJ-Effekten. In Rust geschrieben von Loosy Tale Studio.

 Spiel-Mod · Lua

Silent Hill 2 Co-op Mod

Ein experimenteller Koop-Mod für zwei Spieler samt Launcher für Silent Hill 2 (2024), geschrieben in Lua. Ein inoffizielles Fanprojekt von Loosy Tale Studio.

 KI-Assistent · TypeScript

Maris Local AI

Maris Local AI ist ein privater KI-Assistent, der komplett auf deinem PC läuft: Chat, Coding-Agent, Gedächtnis, Surfen im Web sowie lokale Bild- und Videogenerierung.

 VS-Code-Erweiterung · JavaScript

Travelling Kingdom

Travelling Kingdom ist ein Reisebegleiter für die Seitenleiste von VS Code und Cursor: Zieh die Straße entlang, besuch Reiseziele und heuer Gefährten an, während du programmierst.

 Twitch-Bot · TypeScript

Brackets

Brackets ist ein Twitch-Chatbot, der deinen Zuschauern in deinem eigenen Stil antwortet, während du spielst, mit einem Launcher, der jede Antwort samt Begründung zeigt.
