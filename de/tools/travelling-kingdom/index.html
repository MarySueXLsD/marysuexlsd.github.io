Über Travelling Kingdom

Travelling Kingdom ist ein Reisebegleiter für die Seitenleiste von VS Code und Cursor. Zieh die Straße entlang, besuch Reiseziele, heuer Gefährten an und leiste deiner Figur Gesellschaft, während du arbeitest.

Dein Fortschritt wird im globalen Zustand der Erweiterung gespeichert und bleibt so über Sitzungen hinweg erhalten.
