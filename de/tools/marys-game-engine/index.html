MaryS Game Engine

MaryS Game Engine ist eine modulare 2D-Engine für rundenbasierte Spiele auf C# und MonoGame, mit Drag-and-drop-Editor und KI-Assistent, von Loosy Tale Studio.

Über MaryS Game Engine

MaryS Game Engine ist eine einsteigerfreundliche 2D-Engine mit Fokus auf rundenbasierte Spiele, gebaut in C# auf MonoGame. Mit ihr sollen Entwickler, auch Leute, die nicht programmieren, rundenbasierte Spiele mit minimalem Code bauen können.

Der Editor funktioniert wie ein kleiner Desktop: Ein Ordner Desktop enthält den Startbildschirm, ein Ordner Modules die Editor-Tools und ein Ordner Games jedes Spielprojekt. Jedes Tool, vom Szeneneditor bis zum Asset-Browser, ist ein Modul, das die Engine zur Laufzeit findet und lädt; entfernst du ein Modul, sind seine Funktionen weg.

Was ein Modul erzeugt, bleibt im Ordner des Spiels, sodass ein Spiel weiterläuft, selbst wenn das Tool, mit dem es gebaut wurde, entfernt wird. Spielprojekte lassen sich zum Testen direkt in der Engine starten und als eigenständige MonoGame-Projekte exportieren.
