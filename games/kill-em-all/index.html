About Kill’em All.io

Kill’em All.io is an isometric horde-survival slasher with character progression by Loosy Tale Studio, written in Daslang on the EdenSpark engine. Fight the waves, level up, pick upgrades, and see how long you can last.

The fight moves through five biomes: woods, swamp, frost, citadel and hell. Demo v0.5 is an alpha build with the core combat in place; the tutorial is minimal by design.

Features

  • Isometric horde survival
  • Character progression and upgrades
  • Five biomes: woods, swamp, frost, citadel, hell
  • Its own soundtrack for every biome
