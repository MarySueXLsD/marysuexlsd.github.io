الأدوات

محركات وتعديلات وبوتات وأدوات موسيقية بنيناها على طول الطريق، وكلها مفتوحة المصدر على GitHub.

محرك ألعاب · C#

MaryS Game Engine

MaryS Game Engine محرك ألعاب معياري ثنائي الأبعاد للألعاب بنظام الأدوار، مبني بـ C# وMonoGame، مع محرر بالسحب والإفلات ومساعد ذكاء اصطناعي، من Loosy Tale Studio.

 أداة موسيقية · Rust

SensePad

SensePad تحوّل ذراع التحكم PlayStation DualSense إلى آلة إيقاع لنظام Windows، مع لوحات ضرب ولوبر ومؤثرات DJ. مكتوبة بـ Rust من Loosy Tale Studio.

 تعديل لعبة · Lua

Silent Hill 2 Co-op Mod

تعديل تعاوني تجريبي للاعبَين ومُشغّل للعبة Silent Hill 2 (2024)، مكتوب بـ Lua. مشروع غير رسمي من المعجبين، من Loosy Tale Studio.

 مساعد ذكاء اصطناعي · TypeScript

Maris Local AI

Maris Local AI مساعد ذكاء اصطناعي خاص يعمل بالكامل على حاسوبك: دردشة، ووكيل برمجة، وذاكرة، وتصفح للويب، وتوليد محلي للصور والفيديو.

 إضافة VS Code · JavaScript

Travelling Kingdom

Travelling Kingdom رفيق سفر في الشريط الجانبي لـ VS Code وCursor: امشِ على الطريق، وزُر الوجهات، وجنّد الرفاق بينما تبرمج.

 بوت Twitch · TypeScript

Brackets

Brackets بوت دردشة لـ Twitch يردّ على مشاهديك بأسلوبك أنت بينما تلعب، مع مُشغّل يعرض كل ردّ وسببه.
