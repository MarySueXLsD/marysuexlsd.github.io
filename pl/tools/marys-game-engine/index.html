O projekcie MaryS Game Engine

MaryS Game Engine to przyjazny silnik gier 2D nastawiony na gry turowe, zbudowany w C# na MonoGame. Ma pozwolić twórcom, także tym, którzy nie programują, robić gry turowe przy minimalnej ilości kodu.

Edytor działa jak mały pulpit: folder Desktop trzyma ekran startowy, folder Modules – narzędzia edytora, a folder Games – projekty poszczególnych gier. Każde narzędzie, od edytora scen po przeglądarkę zasobów, to moduł, który silnik wykrywa i wczytuje w trakcie działania, a usunięcie modułu wyłącza jego funkcje.

Wszystko, co stworzy moduł, zostaje we własnym folderze gry, więc gra działa dalej, nawet jeśli narzędzie, którym ją zbudowano, zostanie usunięte. Projekty gier można uruchamiać w silniku do testów i eksportować jako samodzielne projekty MonoGame.
