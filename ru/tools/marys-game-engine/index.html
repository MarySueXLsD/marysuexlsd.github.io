MaryS Game Engine

MaryS Game Engine — модульный 2D-движок для пошаговых игр на C# и MonoGame с редактором drag-and-drop и ИИ-ассистентом от Loosy Tale Studio.

О проекте MaryS Game Engine

MaryS Game Engine — дружелюбный 2D-движок для пошаговых игр, написанный на C# на основе MonoGame. Он задуман так, чтобы разработчики, в том числе те, кто не пишет код, могли делать пошаговые игры почти без программирования.

Редактор устроен как маленький рабочий стол: в папке Desktop лежит стартовый экран, в папке Modules — инструменты редактора, а в папке Games — проекты игр. Каждый инструмент, от редактора сцен до браузера ассетов, — это модуль, который движок находит и загружает во время работы, а удаление модуля отключает его функции.

Всё, что создаёт модуль, остаётся в папке самой игры, поэтому игра продолжает работать, даже если инструмент, на котором её собрали, удалён. Проекты игр можно запускать внутри движка для тестов и экспортировать как самостоятельные проекты MonoGame.
