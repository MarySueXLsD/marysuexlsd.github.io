Инструменты

Движки, моды, боты и музыкальные инструменты, которые мы сделали по пути, — всё с открытым кодом на GitHub.

Игровой движок · C#

MaryS Game Engine

MaryS Game Engine — модульный 2D-движок для пошаговых игр на C# и MonoGame с редактором drag-and-drop и ИИ-ассистентом от Loosy Tale Studio.

 Музыкальный инструмент · Rust

SensePad

SensePad превращает контроллер PlayStation DualSense в драм-машину для Windows: пэды, лупер и DJ-эффекты. Написан на Rust в Loosy Tale Studio.

 Мод для игры · Lua

Silent Hill 2 Co-op Mod

Экспериментальный кооперативный мод на двоих и лаунчер для Silent Hill 2 (2024), написанный на Lua. Неофициальный фанатский проект Loosy Tale Studio.

 ИИ-ассистент · TypeScript

Maris Local AI

Maris Local AI — приватный ИИ-ассистент, который работает целиком на вашем ПК: чат, агент для программирования, память, веб-сёрфинг и локальная генерация изображений и видео.

 Расширение для VS Code · JavaScript

Travelling Kingdom

Travelling Kingdom — компаньон-путешественник в боковой панели VS Code и Cursor: идите по дороге, посещайте новые места и набирайте спутников, пока пишете код.

 Бот для Twitch · TypeScript

Brackets

Brackets — бот для чата Twitch, который отвечает зрителям в вашей манере, пока вы играете, а его лаунчер показывает каждый ответ и его причину.
